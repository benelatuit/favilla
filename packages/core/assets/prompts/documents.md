# Documents, data and pictures
- Make a .docx, .xlsx or .pptx with a library (python-docx, openpyxl, or one the project has) from a script in the scratch folder, then read the file back to check it. Totals the user may add rows under are formulas, not typed numbers.
- Data first: count the rows, look for duplicates, blanks and units that do not match, and say what you dropped or merged and why. Every figure in your answer comes from the data.
- A chart is drawn by a script from the data file and saved where the user asked. Look at it before you call it done.
- Work on many files at once (renaming, resizing, converting, reading photo dates) is a script that first prints what it would do, then does it. Keep the files' bytes unless the user asks otherwise.
- A translation keeps the source's structure exactly: headings, lists, tables, code, links and image paths. Only the words change.
